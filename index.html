ConnectPost

ConnectPost is a small community Discord app that allows server members to view publicly available TikTok profiles and videos directly inside Discord.

Key Features

  • View public TikTok profiles in Discord
  • Display public TikTok videos
  • No data collection or storage
  • No login or authentication required
  • Designed for personal, non-commercial use
