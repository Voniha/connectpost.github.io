Privacy Policy — ConnectPost

Last updated: November 14, 2025

This Privacy Policy explains how ConnectPost handles data when used in my community Discord server.

1. Introduction

ConnectPost is an app that allows members of a Discord community to view public TikTok profiles and public TikTok videos.

The app does not require TikTok Login and does not access private user data.

2. Data Collection

ConnectPost does not collect, store, or process:

  • personal information
  • TikTok user identifiers
  • tokens
  • IP addresses
  • browsing data
  • analytics data
  • login information
  • user interaction history

No data is stored on any server or database.

3. TikTok Content

The app only retrieves TikTok content that is:

  • public
  • accessible without authentication
  • viewable by anyone directly on TikTok

ConnectPost does not access or attempt to access:

  • private videos
  • private profiles
  • "following," "followers," or "likes" data
  • any content that requires OAuth permissions

4. Storage

ConnectPost stores no data at all.

All TikTok content is fetched temporarily only when a user requests it.

Nothing is saved, logged, or archived.

5. Security

The app handles no sensitive information.

Since no data is stored or transferred, the security risk is minimal.

6. Third Parties

ConnectPost does not share any data with third parties.

It does not integrate with analytics, advertising, or tracking services.

7. Contact

If you have questions about this Privacy Policy, please contact the Discord server owner.
